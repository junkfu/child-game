# 小玩具盒

給幼兒園小朋友的網頁小遊戲合輯。免安裝、不用建置、不限時、不扣分。

目前有兩個遊戲：

| 遊戲 | 內容 | 適合 |
|---|---|---|
| **閃亮找碴派對** | 10 個插畫場景，每關 10 個差異 | 約 5 歲 |
| **注音大冒險** | 37 個注音符號，餵點心／找寶石，10 位夥伴收藏 | 4-5 歲（中班／大班） |

## 開啟

直接開啟 `dist/index.html` 就能玩，或在專案目錄執行：

```sh
python3 -m http.server 4173 --directory dist
```

然後開 `http://localhost:4173`。

兩種方式都要能正常運作 —— 專案刻意不用 ES modules 也不 `fetch()` 資料檔，
就是為了保住「雙擊檔案就能玩」。平板是主要的目標裝置，電腦也可以。

## 架構

```
dist/
├── index.html            主選單（遊戲卡片由 shared/catalog.js 產生）
├── menu.js
├── shared/               所有遊戲共用
│   ├── shell.css         設計系統：色票、按鈕、對話框、toast、星星、觸控尺寸
│   ├── core.js           Kid 命名空間、畫面切換、toast、星星、洗牌
│   ├── storage.js        命名空間化的 localStorage
│   ├── audio.js          Web Audio 音效 + 音檔播放
│   └── catalog.js        遊戲清單
├── games/
│   ├── spot/             找碴遊戲
│   └── zhuyin/           注音遊戲
└── LICENSES/
```

**要加第 N 個遊戲**：在 `dist/games/` 開一個資料夾，然後在 `shared/catalog.js`
的陣列加一筆。主選單會自動長出卡片與進度條。

幾個刻意的約束，改的時候請一起維持：

- **傳統 `<script defer>` + 單一全域 `window.Kid`**，不用 ES modules。
  `type="module"` 的 fetch 是 CORS 模式，`file://` 的 origin 是 null，
  一改就再也不能雙擊開啟。
- **資料寫成 inline JS，不要用 `.json` + `fetch()`**，同樣的理由。
- **音檔用 `new Audio()` 播，不要用 Web Audio 的 `decodeAudioData`**，
  後者在 `file://` 下會被擋。Web Audio 只拿來合成回饋音效。
- **路徑一律相對**（`../../shared/x.js`），不要用 `/shared/x.js`。
- 連結寫到 `index.html`，不要只寫目錄（`file://` 沒有伺服器幫忙解析索引）。
- 改了 `shared/` 的檔案，記得把各頁 `?v=1` 的版號往上加（沒有打包器的誠實代價）。

## 進度儲存

單一 key `kid-games-v1`：

```js
{ sound: true, games: { spot: {...}, zhuyin: {...} } }
```

`sound` 是跨遊戲共用的。舊版找碴遊戲的 `huntrix-detectives-v2` 會在第一次開啟時
自動搬進新結構，**舊 key 保留不刪**，萬一退回舊版本進度也不會消失。

## 閃亮找碴派對

`dist/games/spot/`。10 個場景、每關 10 個差異，不倒數、不扣分，提示只暫時圈出位置。

`differences.js` 是每關的差異範圍，格式 `[中心x%, 中心y%, 水平半徑%, 垂直半徑%, 說明, 類型]`。
畫面變化、點擊判定、提示圈圈共用這一份資料。每關包含 6 個物品／形狀／圖案／新增配件的差異，另保留 4 個配色或原版小變化。

右圖透過局部橢圓遮罩，混合 `scenes-varied.png` 的結構變化與 `scenes-edited.png` 的配色變化；遮罩外仍是原圖，避免生成工具重繪時引入沒列入答案的差異。新圖與原圖尺寸相同，座標已依實際生成內容校準。生成提示詞保留在 `dist/games/spot/assets/README.md`。

圈圈以獨立的 CSS `translate` 置中，縮放動畫只改 `transform`，避免動畫覆蓋置中造成向右下偏移。圖片、透明鍵盤按鈕與標記分成明確圖層，圈圈始終在圖片上方。滑鼠與觸控統一由場景處理座標；透明按鈕不攔截指標事件，仍可用鍵盤選取。

新題目以 `edition: 'variety-2'` 另存進度。原題目紀錄封存於 `previousEdition`，避免舊索引指向重新排序的新答案；沒有刪除舊進度。

驗證：`node --test tests/*.test.cjs` 檢查題目結構、版本移轉與實際點擊處理函式。開啟 `dist/games/spot/geometry-check.html` 可重跑 108 組實際 CSS 動畫定位檢查。已於本機預覽實測 10 關 100 個答案、左右兩圖、過關、重玩與手機版點擊／鍵盤選取。

## 注音大冒險

`dist/games/zhuyin/`。10 個單元涵蓋 37 個符號。預設每關 5–7 題：**看符號餵餅乾 → 聽音找寶石 → 夥伴加入野餐**。

每個本單元符號先出一題有字形提示的兩選一配對，再抽兩題三選一聽音挑戰。答錯會重播目標音、顯示字形提示，能繼續嘗試；完成一關就給三顆星。每關對應一位可收藏夥伴，重玩會洗牌，舊版進度沿用。點角色可重播並觸發動作；答對會出現題目插畫，按「收下星星」自行繼續，不趕孩子。

地圖另有自選練習入口：**認識一下 → 描一描 → 聽音／看圖 → 拼拼看**，使用上次選擇的單元。

原有 girl / boy 儲存鍵保留相容，畫面改稱「點心花園／太空樂園」。

| 玩法 | 檔案 | 做什麼 |
|---|---|---|
| 點心任務 | `modes/adventure.js` | 餵注音餅乾、找聲音寶石，夥伴動作與題圖獎勵 |
| 認識一下 | `modes/meet.js` | 逐一介紹本單元符號，沒有對錯 |
| 描寫筆順 | `modes/trace.js` | 跟著虛線描，有判定 |
| 聽音找符號 | `modes/listen.js` | 播發音，選符號 |
| 看圖配注音 | `modes/picture.js` | 看圖，選出開頭的音 |
| 注音拼讀 | `modes/blend.js` | 聲母 + 韻母 = 音節 |

### 這一版的範圍

- **不教聲調**，全部一聲，畫面也不出現聲調符號。
- **拼讀只做二拼**（聲母 + 韻母），不做三拼。
- 單元順序把單韻母排在第 2 關，所以拼讀從第 2 關就能玩，不必等到最後。

### 幾個不明顯但重要的設計

**誘答項刻意和單元脫鉤**（`quiz.js`）。單元是照發音部位分組的，而那正好是最容易混淆的
分組 —— 第 1 關就要小朋友分辨 ㄅ/ㄆ，第 3 關 ㄉ/ㄊ，第 4 關 ㄍ/ㄎ。所以前面幾題從
「已學過的符號裡差異最大的」抽誘答項，只有最後的挑戰題才放進最小對立。

**看圖配注音一定先把整個語詞唸出來**，再問開頭音。這同時解決三件事：消除圖片的命名歧義
（🐶 可能被叫成「狗」ㄍ 也可能「小狗」ㄒ）、示範「聽出開頭音」這件事本身、以及小朋友
根本還不識字。

**描寫筆順用弧長推進判定**，不是「依序通過每個路徑點」。後者對這個年紀會一直失敗。
手指投影到中線上，只記錄走過的最遠處（單調不遞減，手抖不倒退），跑出走廊就停住不推進
—— 這就是判定。走到 85% 就算完成，允許中途放開手指再接上。卡住會先提示，
再卡住就用動畫幫他描完，一樣給星星。**不會有失敗，也不出現紅色。**

**符號是用筆畫資料畫出來的，不是字型文字**（`glyph.js`）。字型的注音字形常和教育部標準
字體有出入，小朋友在學「怎麼寫」的時候這個差異是有意義的；而且描寫的底圖與判定用的中線
必須來自同一份資料，不然看到的形狀和判定的位置會對不起來。順便讓這一頁不依賴 Google Fonts。

### 題目圖片

`assets/adventure/` 包含 10 位黏土風格角色與 56 張題目插畫，分成三張格線圖。圖片依 `WORD_ART_ORDER` 明確對應題目，CSS 定位裁出各格。所有圖片已放進專案，無外部圖片服務依賴；圖片載入失敗仍顯示 Emoji。

生成方式與提示詞見 `dist/games/zhuyin/assets/adventure/README.md`。舊 `assets/PROMPTS.md` 僅留作原版逐張產圖的參考。

### 語音

**全部是預先產好的 m4a**，不是瀏覽器即時語音合成。音源有兩個：

| 用途 | 音源 |
|---|---|
| 37 個注音符號 | **教育部《國語注音符號手冊》真人錄音**（CC BY 4.0） |
| 拼讀音節 / 語詞 / 介面語音 | macOS 內建台灣中文語音合成 |

符號發音是整個遊戲的核心（「聽音找符號」整個玩法就靠它），標準度最值得投資，
而且教育部版唸得比合成音慢、對幼兒比較清楚。音色不同反而變成一種提示：
真人聲＝要仔細聽的題目，合成聲＝旁白說明。

```sh
./tools/make-audio.sh          # 產生全部 132 個音檔（需要 macOS）
./tools/make-audio.sh --check  # 只驗證清單，不寫檔
```

`tools/audio-check.html` 可以逐一試聽驗收。

為什麼不用執行時語音合成：`speechSynthesis` 唸不出注音字元（U+3105–U+3129 是注音符號區，
不是漢字，TTS 前端會當成未知符號丟掉），而想用同音漢字代讀又補不齊 —— **ㄈ、ㄝ、ㄟ、ㄥ
在現代國語裡沒有任何一聲的字可以代讀**。預先產檔還有一個好處：發音可以在出貨前逐一聽過。

實作上三個關鍵細節：

- **教育部音檔的檔名順序不是常見的那個**。是「聲符21 + 韻符13 + 介符3」，
  不是「聲符21 + 介符3 + 韻符13」—— F22 是ㄚ不是ㄧ，ㄧㄨㄩ 排在最後的 F35–F37。
  對照表是從手冊 HTML 裡 `play('aN')` 與 `zhStroker('app','X')` 的配對抽出來的，
  存在 `tools/moe-audio-map.tsv`。照慣例猜會錯 16 個。
- **原始錄音比合成音安靜很多**（rms 0.064 對 0.168），而且 37 個檔彼此也差 2.5 倍。
  直接用的話最重要的符號發音反而最小聲，所以 `tools/prep-moe-wav.py` 會轉單聲道、
  切掉頭尾靜音、把響度對齊，並用峰值上限避免削波。
- **拼讀音節**用 `syllables.js` 裡的代表字產生，不是餵注音字串。
  因為捲舌／舌尖前聲母配 ㄨ 時注音字串不會融合成一個音節
  （`say "ㄓㄨ"` 0.486s vs `say "豬"` 0.324s，被唸成「ㄓ－ㄨ」兩段），
  那正是拼讀最不能犯的錯。

沒有網路或不在 macOS 上時，`./tools/make-audio.sh --say-symbols` 可以讓符號也退回合成音。

## 授權與出處

**注音符號發音音檔**取自教育部《國語注音符號手冊》
（<https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/index.html>）。
手冊本體採「創用CC 姓名標示–禁止改作 3.0 臺灣」，但手冊內含的動畫與**音檔另採
「創用CC 姓名標示 4.0 國際版本」**授權提供，可改作、可商用，標示出處即可；
利用這些檔案視為符合政府資料開放授權條款之規定。
本專案的修改：轉單聲道、切除頭尾靜音、響度正規化、轉成 AAC。
另見[政府資料開放平臺 dataset 44640](https://data.gov.tw/dataset/44640)。

**注音符號的字形輪廓與筆畫中線**取自 [animCJK](https://github.com/parsimonhi/animCJK)
（LGPL-3.0-or-later），37 個符號共 79 畫，筆畫數與教育部《國語注音符號手冊》一致。
詳見 `dist/LICENSES/animCJK-LGPL.txt`。
