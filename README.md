# 小玩具盒

給幼兒園小朋友的網頁小遊戲合輯。**不用安裝、不用建置、不連網**，把 `dist/index.html`
點兩下就能玩。不倒數、不扣分、沒有失敗畫面。

平板是主要的目標裝置，電腦也可以。介面全部是正體中文，語音是台灣發音。

![主選單](docs/01-menu.png)

| **閃亮找碴派對** | 10 個插畫場景，每關 10 個差異 | 約 5 歲 |

### 注音大冒險

每一關住著一位夥伴，帶著四個注音符號。餵對餅乾、找到寶石，牠就來野餐。

![單元地圖](docs/02-map.png)

**看符號餵餅乾** —— 先給字形提示的兩選一，再抽三選一的聽音挑戰。

![餵點心](docs/03-adventure.png)

**描一描** —— 跟著虛線描筆順，有判定但不會失敗。描歪了只是推不動，卡住會先閃提示，
再卡住就用動畫幫你描完，一樣給星星。

![描寫筆順](docs/04-trace.png)

**看圖配注音** —— 先把整個語詞唸出來，再問開頭是什麼音。

## 開始玩

點兩下 `dist/index.html` 就好。或者：

```sh
python3 -m http.server 4173 --directory dist
```

平板要玩的話，讓平板和電腦連同一個 Wi-Fi，開 `http://<電腦IP>:4173`。

`file://` 直開和架伺服器兩種方式都必須能動 —— 專案刻意不用 ES modules、
不 `fetch()` 資料檔，就是為了保住「點兩下就能玩」這件事。

## 設計上的取捨

這個年紀（4-5 歲）大多還不識字，手指也還不太穩。幾個因此而來的決定：

**每一句話都唸得出來。** 指令、選項、鼓勵都有語音。畫面上的字是給旁邊的大人看的。

**沒有失敗。** 不倒數、不扣分、不出現紅色。答錯只是暗掉那一個，繼續找。

**點錯了也要學到東西。** 點錯會先唸出**他實際點到的那個符號**，再放答錯音效。
只放「嗶」一聲的話，孩子只知道錯了，不知道自己按到的是什麼 —— 而點錯的當下，
他正盯著那個符號看，是認識它最好的時機。

**誘答項刻意和單元脫鉤**（`quiz.js`）。單元是照發音部位分組的，
而那正好是**最容易混淆**的分組 —— 第 1 關就要孩子分辨 ㄅ/ㄆ，第 3 關 ㄉ/ㄊ。
所以前面幾題從「已學過的符號裡差異最大的」抽誘答項，最小對立只留給最後的挑戰題。

**看圖配注音一定先唸整個語詞。** 一次解決三件事：消除圖片的命名歧義
（🐶 可能被叫成「狗」ㄍ 也可能「小狗」ㄒ）、示範「聽出開頭音」這個動作本身、
以及孩子根本還不識字。

**描寫用弧長推進判定**，不是「依序通過每個路徑點」—— 後者對這個年紀會一直失敗。
手指投影到筆畫中線上，只記錄走過的最遠處（單調不遞減，手抖不會倒退），
跑出走廊就停住不推進，這就是判定。走到 85% 算完成，允許中途放開手指再接上。

**觸控目標最小 64px**，主要作答按鈕 96px 以上。

### 這一版的範圍

- **不教聲調**，全部一聲，畫面也不出現聲調符號。
- **拼讀只做二拼**（聲母 + 韻母），不做三拼。
- 單元順序把單韻母排在第 2 關，所以拼讀從第 2 關就能玩。

## 語音

**全部是預先產好的 m4a**，不是瀏覽器即時語音合成。

| 用途 | 音源 |
|---|---|
| 37 個注音符號 | 教育部《國語注音符號手冊》**真人錄音**（CC BY 4.0） |
| 拼讀音節 / 語詞 / 介面語音 | macOS 內建台灣中文語音合成 |

符號發音是整個遊戲的核心，標準度最值得投資，而且教育部版唸得比合成音慢、
對幼兒比較清楚。音色不同反而變成一種提示：真人聲＝要仔細聽的題目，合成聲＝旁白。

```sh
./tools/make-audio.sh          # 產生全部 132 個音檔（需要 macOS）
./tools/make-audio.sh --check  # 只驗證清單，不寫檔
./tools/make-audio.sh --say-symbols   # 沒網路時，符號也退回合成音
```

`tools/audio-check.html` 可以逐一試聽驗收。

<details>
<summary><b>為什麼不用瀏覽器的 speechSynthesis（以及三個踩過的坑）</b></summary>

`speechSynthesis` **唸不出注音字元**。U+3105–U+3129 屬於注音符號區、不是漢字，
TTS 前端會當成未知符號丟掉。想改用同音漢字代讀又補不齊 ——
**ㄈ、ㄝ、ㄟ、ㄥ 在現代國語裡沒有任何一聲的字可以代讀**（ㄈ 只有二聲的「佛」，
ㄥ 只有廢字「鞥」）。預先產檔還有一個好處：發音可以在出貨前逐一聽過。

**1. 教育部音檔的檔名順序不是常見的那個。**
是「聲符 21 + 韻符 13 + 介符 3」，不是慣例的「聲符 21 + 介符 3 + 韻符 13」——
F22 是ㄚ不是ㄧ，ㄧㄨㄩ 排在最後的 F35–F37。對照表是從手冊 HTML 裡
`play('aN')` 與 `zhStroker('app','X')` 的配對抽出來的，存在 `tools/moe-audio-map.tsv`。
照慣例猜會錯 16 個。

**2. 原始錄音比合成音安靜很多**（rms 0.064 對 0.168），而且 37 個檔彼此也差 2.5 倍。
直接用的話最重要的符號發音反而最小聲。`tools/prep-moe-wav.py` 會轉單聲道、
切掉頭尾靜音、把響度對齊，並用峰值上限避免削波。

**3. 拼讀音節用代表字產生，不是餵注音字串。**
捲舌／舌尖前聲母配 ㄨ 時，注音字串不會融合成一個音節
（`say "ㄓㄨ"` 0.486s vs `say "豬"` 0.324s，被唸成「ㄓ－ㄨ」兩段），
那正是拼讀最不能犯的錯。

</details>

## 插畫

全部是 AI 生成的，提示詞都留在專案裡，可以照著重產或改風格：

- `dist/games/zhuyin/assets/adventure/` —— 10 位黏土風格夥伴 + 56 張題目插畫，
  裝在三張格線圖裡，用 CSS 定位裁格。提示詞見同資料夾的 `README.md`。

圖片載入失敗時會自動退回大 Emoji，所以**沒有圖也能完整玩**。

## 架構

```
dist/
├── index.html            主選單（卡片由 shared/catalog.js 產生）
├── shared/               所有遊戲共用
│   ├── shell.css         設計系統：色票、按鈕、對話框、toast、觸控尺寸
│   ├── core.js           Kid 命名空間、畫面切換、toast、星星、洗牌
│   ├── storage.js        命名空間化的 localStorage
│   ├── audio.js          Web Audio 音效 + 音檔播放
│   └── catalog.js        遊戲清單
├── games/
│   ├── spot/             找碴遊戲
│   └── zhuyin/           注音遊戲（data/ modes/ audio/ assets/）
└── LICENSES/
```

**要加第 N 個遊戲**：在 `dist/games/` 開一個資料夾，在 `shared/catalog.js` 的陣列加一筆。
主選單會自動長出卡片與進度條。

幾個刻意的約束，改的時候請一起維持：

- **傳統 `<script defer>` + 單一全域 `window.Kid`**，不用 ES modules。
  `type="module"` 的 fetch 是 CORS 模式，`file://` 的 origin 是 null，
  一改就再也不能點兩下開啟。
- **資料寫成 inline JS**，不要用 `.json` + `fetch()`，同樣的理由。
- **音檔用 `new Audio()` 播**，不要用 Web Audio 的 `decodeAudioData`，後者在 `file://` 下會被擋。
  Web Audio 只拿來合成答對／答錯的回饋音效。
- **路徑一律相對**（`../../shared/x.js`），連結寫到 `index.html` 不要只寫目錄。
- 改了 `shared/` 的檔案，記得把各頁 `?v=N` 的版號往上加（沒有打包器的誠實代價）。

**符號是用筆畫資料畫出來的，不是字型文字**（`glyph.js`）。字型的注音字形常和教育部
標準字體有出入，孩子在學「怎麼寫」的時候這個差異是有意義的；而且描寫的底圖與判定用的
中線必須來自同一份資料，不然看到的形狀和判定的位置會對不起來。順便讓整個專案不依賴
Google Fonts。

### 進度儲存

單一 key `kid-games-v1`：

```js
{ sound: true, games: { spot: {...}, zhuyin: {...} } }
```

`sound` 是跨遊戲共用的。舊版的 `huntrix-detectives-v2` 會在第一次開啟時自動搬進新結構，
**舊 key 保留不刪**，萬一退回舊版本進度也不會消失。

## 開發

```sh
node --test tests/*.test.cjs     # 題目結構、版本移轉、點擊處理
```

開發用頁面（不是給小朋友玩的）：

- `dist/games/zhuyin/preview.html` —— 一次把六種玩法都畫出來，方便檢查版面與資料。
- `dist/games/spot/geometry-check.html` —— 重跑 108 組 CSS 動畫定位檢查。
- `tools/audio-check.html` —— 試聽全部 132 個音檔。
