# 獵魔女團・閃亮找碴派對

可愛插畫風的電腦網頁找碴遊戲，適合約 5 歲孩子與家長一起玩。

- 10 個場景，每關恰好 10 個差異。
- 左右圖片都能作答；不倒數、不扣分。
- 提示只暫時圈出位置，不會自動得分。
- 自由選關，瀏覽器會記錄這台裝置的進度。
- 找對、找錯都有音效回饋，也能隨時關掉、重玩當前關卡。

## 開啟

直接開啟 `dist/index.html`，或在專案目錄執行：

```sh
python3 -m http.server 4173 --directory dist
```

然後在電腦瀏覽器開啟 `http://localhost:4173`。無須安裝套件或建置。

## 音效與回饋

音效預設開啟，右上角 `♫` 可切換，選擇會記在這台裝置上。

- 找對：上行的三顆亮音（G5·C6·E6），同時圈出綠色星星圈。
- 找錯：下行的兩顆柔和低音（E♭4·B♭3），並在點到的位置閃一下粉色 `✕`，約 0.7 秒後消失。
- 過關：五顆音的小禮花。

音效用 Web Audio 即時合成，沒有音檔要載入。點到已經找到的地方不會出聲，避免誤判成答錯。

## 插畫與關卡

`dist/assets/scenes.png` 是原始場景圖集。`scenes-edited.png` 是圖片生成工具編修的版本。
右圖只透過 10 個局部遮罩顯示編修內容，遮罩外仍使用原圖，避免整幅重繪引入未列入答案的差異。

`dist/game.js` 的 `regions` 保存每關的 10 個範圍，格式為 `[中心x百分比, 中心y百分比, 水平半徑百分比, 垂直半徑百分比]`。畫面變化、點擊判定和提示共用同一份範圍資料。

遊戲採電腦左右並排大圖版面，最小寬度 1080px。
